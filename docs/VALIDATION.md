# 公开版验证范围

日期：2026-10-08。Windows x64 / Python 3.12.10，RTX 4060。源码、冻结目录和安装器分别验证，不能互相替代。

- 项目 113 项回归测试通过；覆盖语音、回听、词典、字幕阅读、模型包及新增图片分句、悬停计时、坐标、自动启动。
- 资源准备 6 项、模型扩展打包 2 项测试单独执行。
- 合成图片和本工具专门创建的窗口验证英文跨行拼句、分栏、人名前缀与近句选择。自动模式无 ROI 可以启动，悬停等待至少 1.5 秒才处理。不截取其他应用作为测试资料。
- 冻结程序检查 OCR、双向翻译、词典、VAD、专名、本地记忆和语音模型；small.en/base 分别检查 CPU/CUDA，Turbo 为选装。
- 安装器验证脚本在独立目录解压、逐文件检查大小及哈希，验证外置库替换，测量磁盘分配空间，并核对正式安装的注册信息和设置未变。

最终 EXE 的实际验收结果与校验值在发行附件 `release-validation.json`。没有匹配报告时，不能仅凭文件名视为已验证。

## 限制

还未在试用者的抖音窗口或所有电脑/缩放/驱动组合上复测。新增自动采集已移除强制框选条件，但受保护画面、被遮挡窗口和最小化窗口仍有系统限制。

停留 1.5 秒是触发时间，之后仍需要本地识别和翻译；本机测试窗口首次完整结果约 3.4 秒，不是所有机器的性能承诺。静止画面复用识别结果，移动鼠标不运行 OCR。

清晰的英音样本通过只证明链路工作，不代表游戏噪声、人名和各类口音达到固定准确率。小型离线翻译模型不具备通用大模型的篇章理解，谚语仍可能不自然。回听初始化检查不代替人工听音检查。隔离安装不等于覆盖用户正式安装并执行卸载，升级不承诺原子回滚。
