# 使用指南

## 开始听读

1. 打开「文本与回听」，选择目标窗口和输入模式。已有中文字幕、希望补英文字幕时，选「英文声音 → 英文原文字幕」。
2. 在「声音与识别」选择播放游戏/视频的扬声器或耳机。系统音频会包含同一输出设备上的其他应用声音。
3. 模型准备完成后，点击「开始采集」。英文推荐 small.en，中文使用多语种 base；Turbo 为可选更大模型。GPU 不可用时可能回退 CPU。
4. 在「字幕与阅读」选择 A 原文下方或 B 独立字幕条，框选原字幕区域或设置独立字幕位置。先点「测试字幕位置」确认。

画面翻译可直接选择窗口开始，无需先框选。程序通过画面截图和系统回环音频读取，不访问或修改游戏内部文件、不注入进程。

## 图片、网页和软件文字

在「文本与回听」选择「画面英文 → 中文翻译」或「画面中文 → 英文翻译」，再选择识别方式：

- **自动识别整个窗口**：选择窗口后点击开始，按句输出。目标窗口需显示在屏幕上，不能被其他窗口遮住。
- **鼠标停留 1.5 秒取句**：鼠标移到原文附近停稳，选择最近的原文句子；移开会取消旧结果。密集文字推荐此模式，1.5 秒之后仍需识别处理时间。
- **手动框选区域**：点击旁边「框选区域」，用于固定字幕、较小文字或自动检测遗漏的情况。

英译中时识别英文，中译英时识别中文；已有的目标语言文字会尽量过滤。英文换行会按位置拼成句子，各栏分开处理。下方有其他文字时不会强行覆盖，译文保留在实时文本区，可切换 B 独立字幕条。

如果窗口出现在列表却没有文字：先将目标窗口置前、退出最小化，窗口已重启则点击刷新后重选。再检查方向是否正确；尝试放大文字或框选区域。受保护的视频或游戏画面仍可能无法截取，程序不会通过注入或修改目标文件绕过限制。

## 长句、查词和回听

- 阅读保护会为长句分页，支持暂停翻页和追到最新；暂停阅读不停止采集。自然停顿可选 1.2 秒，长停顿可选 1.8 秒，等待越久最终断句越晚。
- 双击英文单词打开小词典；右侧独立词典也可输入英文单词/短语。中译英结果中的英文同样可查。此词典不是整句中文查询翻译器。
- 回听区选择最近片段，播放一次或循环。回听期间会暂停识别输入，避免程序把自己的播放再次转录；停止回听后恢复。
- 片段有长度与总缓存上限；极长句可能只有对应的最近片段，不承诺完整会话录音。清空缓存或退出后不能恢复音频。
- 「纠正最近一句」和「词库与记忆」用于保存本地纠正与专名。更正记录不能保证未来所有相似发音都正确。

## 空闲与占用

Turbo 是可选模型；公开完整安装器内置 CPU/NVIDIA 运行支持。移除模型前先退出程序；不要删除当前所选模型后继续期待识别正常。静音 3 分钟释放模型可减少长期空闲占用，但重新开始说话时需要唤醒时间。关闭该选项会保留已加载模型，并不意味着持续高强度推理。

## 快捷键

| 组合键 | 功能 |
|---|---|
| Alt + Shift + T | 切换 A/B 字幕 |
| Alt + Shift + P | 开始/停止采集 |
| Alt + Shift + H | 暂隐/恢复字幕 |
| Alt + Shift + R | 暂停/继续翻页 |
| Alt + Shift + L | 追到最新 |
| Alt + Shift + S | 显示主面板 |

快捷键冲突时通过主界面操作。托盘不可用时窗口按普通程序最小化。
