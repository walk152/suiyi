# 本地数据与网络

## 运行时

开始采集后，程序读取所选窗口、鼠标停留附近的有限区域或手动区域，或所选输出设备的系统回环音频。不会使用麦克风。输出设备上其他程序的声音也可能被读到，请按实际需要选择设备并停止采集。

推理、词典查询和纠正记忆均在本机；项目没有遥测、登录、上传录音或在线翻译回退。推理子进程设置离线环境并通过 Python 审计钩子阻止 `socket.connect`。这不是操作系统级防火墙，不是对所有底层第三方库行为的绝对隔离证明。

## 保存什么

| 内容 | 位置与保存方式 |
|---|---|
| 设置、窗口区域 | 源码运行时在项目 `settings.json`；冻结安装版在 `%LOCALAPPDATA%/Suiyi/settings.json` |
| 用户纠正、学习记忆 | 同一数据目录的 `learning.sqlite3`；可能含你主动保存的句子和专名 |
| 日志 | 异常时写入同一数据目录；可能含文件路径和错误上下文 |
| 实时历史文本 | 内存中最近 40 段，程序不自动导出完整历史 |
| 回听音频 | 内存中有上限的短片段，总计约 60 秒；不保存录音文件 |

关闭程序后，可自行删除上述设置/学习数据库来重置。它们不会进入本项目 Git 提交或源码导出。提交 Issue 前请检查截图、日志、字幕内容，不要上传私人对话或个人目录路径。

## 准备资源时

`pip` 访问 Python 软件包来源；`download_models.py` 访问模型上游；`tools/prepare_dictionary.py` 按需访问 GitHub 的 ECDICT 数据。上游会收到正常下载请求的 IP 等信息。这些是用户明确运行的准备步骤，不调用收费推理服务，不在日常推理中自动执行。下载失败不会自动切换到收费接口。
